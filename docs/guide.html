01 · The system at a glance

01Three parts

The Pi is the heart of the object. It computes every frame itself and sends it to the panel. The phone is only a remote: close it, and the panel keeps going.

The panel64×64 LEDs. The glowing surface. It computes nothing, it displays.
The controllerA small board running WLED that physically drives the panel. It receives the images over the network.
The Raspberry PiGenerates the animations, around the clock, and streams them to the controller. It also serves the app to your phone and remembers your settings and scenes.
An image's journey The Pi paints a 64×64 frame → sends it over Wi-Fi to the controller (DDP protocol) → the controller lights the panel. Your phone only tells the Pi what to paint.
02 · The hardware

02The full list

PanelHUB75 LED panel, 64×64.

MicrophoneOptional. USB, for the sound modes.

03 · The wiring

03Panel and controller

Everything is done with the power off. Plug in the supply only at the very end, once every connection is checked.

  1. The data ribbonConnect the HUB75 ribbon between the controller's X1 output and the panel's input (marked "IN", arrow pointing into the panel).
  2. The panel's 5 VConnect the supply's 5 V terminals to the panel's power terminals, respecting + and –.
  3. The controller's 5 VPower the controller from the same supply. Check the polarity once more.
  4. Power onPlug the supply in. The controller boots, the panel initialises.
Polarity Reversing + and – on the 5 V is the one real way to damage the hardware. When in doubt, check again before plugging in.

04 · WLED

04Get the panel online

  1. Join the controllerOn first boot it creates a Wi-Fi network called WLED-AP. Connect your phone to it and the WLED page opens.
  2. Put it on your networkIn WLED's Wi-Fi settings, enter your home network's name and password. The controller joins the same network as the Pi.
  3. Declare the matrixIn WLED's LED / 2D settings, set a 64 × 64 matrix. WLED's test effects should now fill the panel.
  4. Note its nameWrite down the controller's network name (wled-xxxxxx.local) or its IP address. You will give it to LUMEN in step 07. The name is better: it survives a change of network.
Keep your network to yourself Your Wi-Fi name and password go into WLED and into Raspberry Pi Imager — nowhere else. Neither LUMEN nor this guide ever needs them.

05 · The Raspberry Pi

05A headless system

A light system without a desktop, configured in advance: network, remote access, name. Everything is done from your computer with Raspberry Pi Imager.

  1. Install Raspberry Pi ImagerFrom raspberrypi.com. Insert the microSD card into your computer.
  2. Choose the model and the systemYour Raspberry Pi model, then Raspberry Pi OS Lite (64-bit).
  3. Fill in the settings (the gear, "Edit settings") before writing:
    Hostnamelumen — the Pi will answer at lumen.local.
    SSHEnabled, with password authentication.
    UsernameA name and a password of your choice. The install script assumes laurent: use it, or adapt the script (step 06).
    Wi-FiYour home network, the same one the controller joined.
    Time zoneYour own — the "day" mode follows the real hour.
  4. Write the cardWait for the verification, put the card in the Pi and power it on.
  5. ConnectA minute or two later, from your computer:
TerminalComputer
% ssh laurent@lumen.local
First connection SSH asks you to confirm the machine's fingerprint: type yes, then your password. The prompt changes to laurent@lumen:~ $ — you are on the Pi.

06 · Install LUMEN

06Three commands

The code is public on GitHub. You fetch it straight onto the Pi, then a script turns it into a service that starts on its own at every boot.

Fetch and installPi
$ sudo apt-get install -y git
$ git clone https://github.com/lnyssen/lumen.git ~/lumen
$ cd ~/lumen && ./setup-service.sh

What the script does

numpyInstalls it if needed (once, about a minute). The animation engine relies on it to stay fluid on a small Pi.
lumenThe main service: the animation engine and the server on port 8000. Restarted automatically if it ever stops.
lumen-alexaThe voice-control service (step 08). Harmless if you have no Echo.
Update rightsLets the app restart the service after an update sent from the phone (step 09).
Check that it runsPi
$ systemctl status lumen

You should read active (running). From then on, the Pi runs the show by itself.

Another username? setup-service.sh assumes the user laurent and the folder /home/laurent/lumen. If you chose another name, replace both in the script before running it.

07 · Use it

07From your phone

  1. Same networkYour phone must be on the same Wi-Fi as the Pi and the controller.
  2. Open the appIn the browser, go to http://lumen.local:8000 (or the Pi's IP address, port 8000).
  3. Point it at the panelOpen Adresse du panneau (panel address) and enter the controller's name or IP from step 04. The top of the screen then reads En ligne (online).
  4. Keep it on the home screenShare → Add to Home Screen. LUMEN then opens full-screen, like an app.

The screen

A live preview of the panel, then the Animation and the Palette, and the sliders that shape the current animation (speed, scale, blend…). Along the bottom:

PauseFreezes the current frame.
VeilleSleep: switch off at a set time, or after 15 min, 30 min, 1 h.
AléatoireRandom: LUMEN changes animation on its own.
AlimentationPower: on / off.
JournéeDay: the mood follows the real hour, from dawn to night.
ScènesScenes: save the current look in a slot, recall it with a tap.
LumièreLight: brightness, automatic adaptation to the room's light, Ambiance sonore (the object follows the room's mood: lively when it moves, calm in the silence), panel address and updates.

Any animation can be worn in any of the 66 palettes. The camera and sound families need the optional webcam and microphone; the others need nothing else.

08 · Voice control

08With an Echo

Fully local: no cloud, no account to link. The Pi poses as a few smart plugs that the Echo finds on its own.

  1. DiscoverOnce installed, say: "Alexa, discover devices." The LUMEN plugs appear.
  2. SpeakSwitch the panel on or off, or call a mode: day, random, music, plasma. The plugs carry French names (Lumen, Journée, Aléatoire, Musique, Plasma) — say them as written.

09 · Update

09Two ways

From the Pi

Fetch the latest versionPi
$ cd ~/lumen && git pull && ./setup-service.sh

From the phone

Open Lumière → Mettre à jour l'app depuis ce téléphone (update from this phone), or go straight to http://lumen.local:8000/update. Choose the update's .zip file and confirm: the Pi installs it and restarts by itself. Reload the app five seconds later.

10 · Troubleshooting

10If it gets stuck

lumen.local not foundThe Pi takes a minute or two to appear after power-on. Check it is on the right Wi-Fi; as a last resort, use its IP address.
Blank pageOn the Pi, systemctl status lumen should read active (running). If not, run ./setup-service.sh again.
Panel stays blackCheck the 5 V and the ribbon on X1. In WLED, a test effect should light the panel on its own.
The app says offlineThe panel address is wrong, or the controller changed IP: enter its wled-xxxxxx.local name instead.
Old version on the phoneOpen the app once in a private tab, or remove and re-add the home-screen icon.
No camera / no soundCheck the USB webcam or microphone is plugged into the Pi. They switch on only when an animation needs them.
The golden rule Go link by link: panel (does it light?), controller (does WLED answer?), network (same Wi-Fi?), Pi (is the service running?), app (right panel address?). Find the link, and you have found the fault.
